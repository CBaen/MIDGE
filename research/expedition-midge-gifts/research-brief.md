# Research Brief: Gifts for Midge — Expanding Her Senses, Speed, and Reasoning

## Date: 2026-03-05
## Project: MIDGE (Mae for trading)

### Problem Statement
Midge needs more external input, more processing power, and deeper reasoning capability. She's throttled — not enough data sources, not enough concurrent processing, not enough ability to trace cascading effects across domains. She can see financial patterns but can't yet feel a hurricane forming and trace its ripple through supply chains to a factory in Ohio to a stock price in New York.

### Expected Outcome
Midge becomes the ultimate pattern recognizer for day trading and swing trading — connected to enough of the world's signal that she can detect precursors, stack patterns, trace causal chains, and say with confidence: "This is going to happen. These are the precursors. This is the timeline." She should be able to reason internally about why patterns are forming, not just that they exist.

### Current State
- 146 systems (92 core + 54 market), 4,384+ tests, 33-layer bootstrap
- 28+ data sources across 11 domains, ConvergenceAlerter as crown jewel
- Pattern Archaeology v2 running excavation across 3,237 symbols
- Thompson Sampling for signal reliability, hypothesis engine for theory generation
- Previous expedition (competitive-edge) produced 4-phase action plan — Phases 0-1 not yet executed
- Polygon.io ($29/mo) active for bulk historical data
- Pure Python on Wardenclyffe (Win11 desktop, Docker/Qdrant/Ollama installed)

### Project Direction
Make Midge the best financial pattern recognizer by giving her maximum sensory input, causal reasoning, and self-directed intelligence. Day/swing trading timescales (hours to weeks). The earnings fund housing work — Guiding Light's core mission.

### Constraints
- Mae's 8 Mathematical Laws (triadic witnessing, holon protocol, fractal self-similarity, etc.)
- All new data sources must wire through BoundaryMembrane + InputValidator (immune system)
- New systems must register in ConnectionRegistry with triadic connections
- Bootstrap layer 33 (market) handles all market module wiring
- Zero regression policy on 4,384+ existing tests
- No external infrastructure servers — pure Python

### Destructive Boundaries
- Do NOT suggest replacing Mae's biological architecture or core systems
- Do NOT suggest abandoning Thompson Sampling or ConvergenceAlerter
- Do NOT suggest cloud-only solutions — Midge runs on consumer hardware
- Do NOT suggest enterprise-tier APIs without free/affordable alternatives

### Research Angles

**Team 1: Real-Time Zeitgeist Feeds**
Find free/cheap APIs and tools for real-time social media, news, and cultural signals actionable on day/swing timescales. Reddit API, X/Twitter API alternatives, financial news APIs, RSS aggregation, economic event calendars. What's available as of March 2026, what's free, what delivers signal not noise?

**Team 2: Causal Chain Engine**
Find open-source tools for multi-hop event propagation modeling. How do you go from "hurricane hits Gulf Coast" to "ethylene production drops" to "auto parts shortage" to "Ford earnings miss" to "stock drops" — with timing estimates at each step? Supply chain mapping, event cascade modeling, knowledge graph tools.

**Team 3: Novel Pattern Recognition from GitHub/Reddit**
Scour GitHub and Reddit (r/algotrading, r/quant, r/MachineLearning, r/datascience) for projects from 2025-2026 doing multi-domain anomaly detection, alternative data analysis, event correlation, or market pattern recognition. What open-source tools have appeared that could give Midge new capabilities?

**Team 4: LLM-Powered Reasoning via Ollama**
How to integrate local LLMs (Ollama is already installed) for pattern interpretation, hypothesis narrative generation, and "internal conversation" about detected convergences. Not replacing Midge's statistical engine — augmenting it with reasoning. When Midge detects a 4-domain convergence, an LLM could explain WHY these domains are connected, generating causal narratives.

**Team 5: Consumer Hardware Optimization**
How to maximize throughput on Wardenclyffe (Win11 desktop). Async processing patterns, native Python extensions (Rust via PyO3, C extensions), memory-mapped data, concurrent API fetching, process-level parallelism for Windows. Focus on day/swing trading latency requirements — not HFT, but "detect within minutes, act within the hour."

### Team Size: 5
Five genuinely independent angles — each represents a different dimension of Midge's growth. Feeds (input), Causality (understanding), Discovery (new tools), Reasoning (intelligence), Speed (throughput).

- ApeWisdom is already wired into the convergence engine.
- Unusual Whales (options flow) is deprioritized by Guiding Light — not a current focus.
